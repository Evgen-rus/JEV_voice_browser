# Русское видеодемо voice-browser

Целевая длительность: 3–5 минут. Слева держите управляемое окно Chromium, справа — страницу управления `http://localhost:8787` в обычном Chrome или Edge.

## Подготовка

```powershell
cd D:\My_dev_project\JEV_voice_browser
node --env-file=.env src/server.js
```

Выберите в шапке `Русский` (он выбран по умолчанию, `ru-RU`), включите микрофон и разрешите доступ. Переключение на `English` меняет распознавание на `en-US` без перезапуска сервера.

## Проверка перед записью

```powershell
npm test
```

При уже настроенном ключе и согласии на live-вызовы:

```powershell
npm run test:integration
npm run demo:ci
```

Не называйте заранее проценты, стоимость или задержку: показывайте фактические значения текущего запуска. Chrome Web Speech API зависит от сети, качества микрофона и разрешений сайта; реальные страницы могут менять разметку или блокировать автоматизацию.
