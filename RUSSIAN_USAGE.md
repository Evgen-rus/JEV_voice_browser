# Русское управление voice-browser в Windows

## Требования и установка

Нужны Node.js 20+, npm, Chrome или Edge для Web Speech API и ключ TypeSafe/JEV.

```powershell
cd D:\My_dev_project\JEV_voice_browser
npm install
npx playwright install chromium
```

Создайте `.env` в корне проекта:

```env
TYPESAFE_API_KEY=your_typesafe_api_key_here
```

Не публикуйте ключ и не добавляйте его в Git.

## Запуск

```powershell
node --env-file=.env src/server.js
```

Откройте `http://localhost:8787` в обычном Chrome или Edge. Страница управления получает речь с микрофона, а отдельное окно Chromium, запущенное Playwright, выполняет действия.

В шапке выберите `Русский` или `English`. По умолчанию используется `ru-RU`; английский режим использует `en-US`. При смене языка активная recognition-сессия перезапускается автоматически, сервер перезапускать не нужно.

## Проверки

Unit-тесты не используют сеть:

```powershell
npm test
```

Следующие команды требуют действующего API-ключа, выполняют live-вызовы Jev и могут расходовать API-кредиты:

```powershell
npm run test:integration
npm run demo
npm run demo:ci
```

## Если распознавание речи не работает

- Используйте Chrome или Edge; Firefox и Safari не поддерживают нужный Web Speech API.
- Разрешите микрофон для `http://localhost:8787`.
- Проверьте выбранный язык перед включением микрофона.
- После долгой тишины браузер может завершить recognition-сессию; страница запускает её снова.
- Если появляется `not-allowed`, проверьте разрешения сайта и Windows.
- Распознавание зависит от сети и сервиса браузера; при сбое используйте текстовое поле.

## Если Jev отвечает 401

```powershell
Get-Item Env:TYPESAFE_API_KEY -ErrorAction SilentlyContinue
Remove-Item Env:TYPESAFE_API_KEY -ErrorAction SilentlyContinue
node --env-file=.env src/server.js
```

Интеграция с реальными сайтами ограничена их текущей разметкой, защитой от автоматизации и доступностью элементов в snapshot. Команды внутри iframe и элементы за пределами лимита snapshot могут быть недоступны.
